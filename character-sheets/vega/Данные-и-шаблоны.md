# Вега: JSON и HTML-шаблоны

Оформление всех персонажей задаётся одним файлом `character-sheets/styles.css`. Обе страницы подключают его через `../styles.css`; сборка сохраняет сделанные в общем файле правки.

`index.html` и `level-2.html` используют одинаковые шаблоны с переменными, `sheet-engine.js` и `sheet-ui.js`. Они не содержат заранее заполненных строк характеристик или навыков: браузер разбирает исходный JSON и рассчитывает лист.

Источник: `SecretsOfSokolKeep/heroes/Антон - Вега.json`. В `rules.json` записаны только отсутствовавшие в нём решения: Убежище на втором уровне и разрешённое ведущим владение инструментами алхимика. По уточнению пользователя источник исправлен: точный стартовый набор, кинжал, 16 зм и состояние «Испуганный» при виде пауков вместо штрафа −5. Профиль карабина удалён. Основные значения берутся из самого экспорта, а не из файла настроек.

После изменения источника запустите из корня проекта:

```powershell
node character-sheets/vega/build.cjs
```

Оба HTML обновятся без ручной правки разметки. При открытии через `file://` они читают встроенный исходный JSON-снимок; при HTTP-просмотре читают соседний `character.json` заново. Для открытия и печати достаточно браузера с JavaScript. Печать: Ctrl+P, A4, книжная ориентация, 100%, отключить колонтитулы браузера.

`sheet-model.json` — сохранённый старый артефакт предыдущей реализации; новые страницы и `build.cjs` его не используют. Полные описания правил — в переиспользуемых справочниках скилла; зависящие от героя числа в них заданы переменными.
