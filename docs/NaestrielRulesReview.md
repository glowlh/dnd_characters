# Наэстриель: сверка печатного листа с правилами

Дата: 02.11.2026. Основной лист — для 1-го уровня; отдельное дополнение — для 2-го. Используются правила D&D 2024, как указано в JSON, а не PHB 2014. Исходный экспорт 2-го уровня сохранён без изменений.

## Уровни и вычисления

По [официальным правилам барда 2024](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes): на 1-м уровне доступны Бардовское вдохновение и магия; на 2-м добавляются компетентность и «Мастер на все руки». Количества заклинаний и ячеек взяты из таблицы класса.

| Показатель | Уровень 1 | Уровень 2 |
|---|---|---|
| Максимум хитов | 8 + CON 2 = 10 | 10 + 5 + CON 2 = 17 |
| Кости хитов | 1к8 | 2к8 |
| Ячейки 1-го уровня | 2 | 3 |
| Заговоры | 2 | 2 |
| Подготовленные заклинания | 4 | 5 |
| Итоговый бонус Выживания | +3 | +5, компетентность |
| Итоговый бонус Убеждения | +4 | +6, компетентность |
| Навыки без владения | Модификатор характеристики | Модификатор характеристики +1, «Мастер на все руки» |

Характеристики в обоих случаях: STR 8, DEX 15, CON 15, INT 10, WIS 12, CHA 15. PB +2, КД 13, инициатива +2, пассивное Восприятие 13, Сл магии 12, атака заклинанием +4. КД рассчитан для кожаного доспеха. Прирост хитов на 2-м уровне фиксированный; при броске кости он может отличаться. Колонка навыков содержит итоговый бонус с модификатором характеристики, владением, компетентностью или «Мастером на все руки» на соответствующем уровне. Повторно прибавлять модификатор при броске не нужно.

По прямому выбору пользователя «Приказ» добавляется только на 2-м уровне. На 1-м подготовлены Волна грома, Героизм, Диссонирующий шёпот и Невидимый слуга. Оба заговора сохраняются с 1-го уровня.

## Происхождение и владения

[Шарлатан, PHB 2024 в лицензированном справочнике Roll20](https://roll20.net/compendium/dnd5e/Backgrounds%3ACharlatan?expansion=32231&iframe=true) соответствует выбранным DEX +1, CON +2, Обману, Ловкости рук, набору для фальсификаций и черте «Одарённый». [Одарённый / Skilled](https://www.dndbeyond.com/sources/dnd/br-2024/feats#Skilled) даёт три владения навыками/инструментами. В JSON выбраны Акробатика, Атлетика и Восприятие. Всего с классом и видом получается десять владений уже на 1-м уровне.

Особенность Ченжлинга с преимуществом на проверки Харизмы в изменённом облике соответствует обновлению из *Eberron: Forge of the Artificer*: это подтверждает [официальное описание обновлённых видов](https://www.dndbeyond.com/posts/2017-how-eberron-forge-of-the-artificer-reimagines). Отнесение конкретного персонажа к этой версии — вывод по совпадению текста исходного листа; JSON не хранит название книги. Остальные ограничения превращения сохранены по исходнику. Этот вид не объявляется вариантом из PHB.

**Воровской жаргон:** исходный выбор сохранён с пометкой «с разрешения ведущего». Согласно [выбору языков 2024](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character#ChooseLanguages), обычное происхождение даёт Общий и два стандартных языка; Воровской жаргон относится к редким и требует отдельного основания. У этого барда такое основание в JSON не указано. Самостоятельно заменять выбранный язык другим не стали.

## Заклинания

Пять заклинаний 1-го уровня описаны русским пересказом полных текстов SRD 5.2.1, уже включённых в локальный HTML в `SPELL_DETAILS_SRD`; название, школа, дистанция, сотворение, компоненты, длительность и эффекты выводятся на лист. Для увеличения ячейки сохранён отдельный абзац. Официальные открытые источники для сопоставления: [описания заклинаний 2024](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions) и [SRD](https://www.dndbeyond.com/srd).

**Дружба:** в `LSS_PERSONAL_SPELLS` конструктора стоит HB и дистанция «в пределах видимости». Для печатного листа дистанция исправлена на **10 футов**, как в [Friends, PHB 2024, лицензированный справочник](https://roll20.net/compendium/dnd5e/Spells%3AFriends?expansion=32231&iframe=true). Остальной текст исходника соответствует механике очарования, ограничению на гуманоидов и автоматическому успеху цели в указанных ситуациях. Длительность явно оформлена как концентрация до 1 минуты. Это исправление относится только к представлению, исходный JSON не менялся.

**Злая насмешка.** По выбору пользователя заменяет «Оживлённый череп» из исходного экспорта. На листе используется версия из PHB 2024, с. 337. [Карточка заклинания](https://www.dndbeyond.com/spells/2619216-vicious-mockery)

Примечание о временных хитах Героизма соответствует [правилам урона и лечения 2024](https://www.dndbeyond.com/sources/dnd/br-2024/playing-the-game): временные хиты не суммируются. Для Наэстриель указано конкретное число — 2.

## Проверка печати

PDF создаются из той же структурированной модели, что и HTML, с внедрёнными кириллическими шрифтами. Основной PDF содержит две страницы A4, дополнение — одну. Блоки спасбросков и счётчики-кружки не выводятся. Упоминания спасбросков в текстах заклинаний сохранены: это часть механики заклинаний.

Ранее созданные PDF отрендерены в изображения и визуально проверены. По уточнённому запросу основной результат — HTML + CSS для печати через браузер. В `styles.css` задан A4 с полями 10 мм, сняты фон и тени, сохранены печатные колонки и запрещены разрывы внутри карточек. Проверка PDF не является проверкой браузерной печати; окончательное разбиение HTML проверяется в предпросмотре браузера.
